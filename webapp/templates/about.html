About this project

What's a WARN notice?

The Worker Adjustment and Retraining Notification (WARN) Act requires employers planning a mass layoff or plant closing to give 60 days' advance notice. Every state collects these filings and (mostly) publishes them — but every state publishes them differently: some as web tables, some as Excel files, some as PDFs, a few not at all.

What this site does

A scraper collects notices from official state labor department sources, cleans up the wildly inconsistent formats into one common structure, and stores them in a database. This site searches that database, and an alert system emails subscribers when a new notice matches filters they've set.

Limitations, honestly

  • WARN notices are filed at the company level, not by individual job title — there's no way to search "was my specific role affected," only "did my employer file a notice."
  • A few states (Arkansas, Wyoming) don't publish WARN data publicly at all — it's confidential by state law.
  • A handful of other states aren't collected yet because their sites block automated access or the data has moved.
  • Not every field is available for every state — some publish no headcount, some no exact date.

Source

Every notice links back to the state filing it came from. This is an independent project and is not affiliated with any state government or the U.S. Department of Labor.
